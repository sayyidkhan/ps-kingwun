# Khin Woon

A Next.js landing page for Khin Woon’s Sarawak + Singapore real estate negotiator positioning. The two portraits live in `assets/` and are imported by the page.

## Run locally

```bash
npm install
npm run dev
```

Open <http://localhost:3000>. Run `npm run build` to check the production bundle.

Contact links and professional credentials should be added after Khin Woon confirms the correct details.
